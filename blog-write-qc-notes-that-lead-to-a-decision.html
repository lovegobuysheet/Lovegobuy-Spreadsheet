Shopping notes

Better QC notes for your Lovegobuy spreadsheet

2026-10-23 · 3 min read

Turn a vague “check this” note into a clear question, reference and next action.

“Looks fine?” is a difficult note to act on. If you return to it a few days later, you may not remember which detail bothered you. A Lovegobuy spreadsheet works better when each QC note points to something specific you can check.

Start with the expected option

Keep the original listing, selected color, selected size and order reference beside the warehouse record. These are the details you are comparing the photos against. Without them, it is easy to judge an image without knowing what was actually ordered.

If a detail came from the seller page, label it as listing information. If it came from a warehouse image, label it as a photo observation. Keeping those two sources apart makes disagreements easier to resolve.

Ask one clear question

Instead of “size issue,” try “Can the chest width be confirmed using the same method as the listing chart?” Instead of “wrong color,” note which reference image you are comparing and whether lighting could explain the difference.

Do not treat a photo as proof of every quality detail. It may help with visible color, shape or a measurement, while leaving fabric feel and durability unanswered. Your spreadsheet can say exactly what remains unknown.

Record the response beside the question

Give the question a date, save the relevant photo reference and note the response when it arrives. Avoid replacing the original concern with a simple “done.” A short trail helps you remember why you accepted the answer or asked for another check.

A hypothetical entry might read: “Sleeve measurement unclear; requested a clearer reference; decision pending.” That is more useful than a green check mark with no explanation.

Keep the decision separate from the evidence

“Keep,” “ask again” and “review return options” are decisions. They should follow the evidence rather than stand in for it. Check the current service terms and any applicable deadlines before acting; a spreadsheet note does not reserve a return right.
