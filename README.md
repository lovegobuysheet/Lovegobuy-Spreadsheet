# Lovegobuy Spreadsheet

An independent decision journal for product research, warehouse QC and shipping comparisons.

**[Read the complete guide](https://lovegobuysheet.github.io/Lovegobuy-Spreadsheet/)** · **[Browse FashionReps product links](https://fashion-reps.net/lovegobuy-spreadsheet)**

## Start with a useful shortlist

Save the original listing, exact variant, seller and date checked. Compare the differences between visually similar products rather than assuming matching photos mean identical goods.

## Review your own QC evidence

Match the order reference, size, colour and quantity. Record measurements and photo references, then mark keep, return or needs review. Resolve open questions before dispatch.

## Compare shipping quotes

Record packed dimensions, weight, route eligibility, currency and quote date. Review restrictions, tracking, compensation and any charges excluded from the quote. Transit estimates are not guarantees.

## Download the template

[decision-log.csv](decision-log.csv) contains blank column headings for Excel or Google Sheets. Use one row per variant, and duplicate the product reference when comparing route quotes. No invented products or endorsements are included.

## Discovery and references

The [FashionReps Lovegobuy catalogue](https://fashion-reps.net/lovegobuy-spreadsheet) provides a discovery starting point. Verify the original listing and current price. Check [Lovegobuy](https://www.lovegobuy.com/) for current platform terms. This project is independent and not operated by Lovegobuy.
